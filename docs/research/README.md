# Conversaciones con usuarios potenciales

El curso pide las notas de **3 conversaciones**; aquí hay 4. Cada una va en un archivo propio, de `01_conversacion.md` a `04_conversacion.md`. Usa la plantilla `plantilla_conversacion.md`.

- Identifica a cada persona por su **cargo o rol**, nunca por su nombre.
- Pregunta por **hechos pasados** ("¿cuándo fue la última vez que…?") y no por opiniones sobre la idea ("¿te gustaría…?"). Es el consejo de la guía *How to Talk to Users* de Y Combinator.
